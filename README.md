## Project Objective

The objective of this project is to develop a Weather Application that provides real-time weather information and forecasts for cities around the world. The application helps users access accurate weather data through an interactive and user-friendly interface.

---

## Project Description

The Weather Application is developed using Python, Streamlit, and the OpenWeatherMap API. It allows users to search for weather information for any city worldwide and view detailed weather conditions including temperature, humidity, wind speed, pressure, visibility, sunrise, and sunset timings.

The application also provides a five-day weather forecast and supports temperature conversion between Celsius and Fahrenheit.

---

## Steps Performed

1. Designed an interactive user interface using Streamlit.
2. Integrated the OpenWeatherMap API to fetch weather data.
3. Implemented city search functionality.
4. Retrieved and displayed current weather information.
5. Added weather details such as humidity, pressure, visibility, and wind speed.
6. Implemented sunrise and sunset information display.
7. Added Celsius and Fahrenheit unit conversion.
8. Developed a 5-day weather forecast section.
9. Implemented error handling for invalid city names and API responses.
10. Tested the application using multiple cities and weather conditions.

## How to Run the Project

### Install Required Packages

```bash
pip install streamlit requests
```

### Run Application

```bash
python -m streamlit run PatelRudra_Task4_WeatherApp.py
```

---

## API Configuration

1. Create a free account on OpenWeatherMap.
2. Generate an API key.
3. Open `PatelRudra_Task4_WeatherApp.py`.
4. Replace:

```python
API_KEY = "YOUR_API_KEY"
```

with your OpenWeatherMap API key.
